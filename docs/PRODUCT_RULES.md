# Product invariants

These outrank any page composition or navigation suggestion.

1. Global discovery contains only admin-approved structured project content.
2. Projects/products/startups are the primary objects. There is no global social feed.
3. Projects compete; builders do not. Builder profiles never rank people or display follower counts.
4. Recruitment belongs to a project and never enters competitions.
5. Verified authenticated users can support a project once per weekly edition. There are no negative votes.
6. Voting closes at the period’s deadline even before a background or request-driven finalizer runs.
7. Locked historical periods, result rows, supports, and legitimately earned or awarded achievements are permanent.
8. Longer-period rankings use versioned normalized performance instead of lifetime raw votes.
9. The Weekly Drop is a signature exhibition, not a secondary dashboard widget.
10. One underlying project model supports category/facet overlap and attached recruitment without duplicate projects.
11. Optional future build logs belong only to profiles and require separate moderation.
12. Design quality, accessibility, and a strong mobile experience are first-class requirements.

Navigation and composition may evolve. A more useful screen should replace a suggested layout when these rules remain intact.
