# Drop / Otherworld

User-directed evolution on design/maximalist. Previous poster-wall checkpoint: 34b29cf. Product rules remain authoritative; no backend or ranking changes.

UI UX Pro Max references: Gen Z Chaos / Maximalism, Kinetic Typography, and organic flowing SVG shapes. The generic generated Swiss recommendation was rejected as inconsistent with the user's explicitly experimental direction. This composition uses the focused styles' motion typography, layered depth, organic curves and bold exhibition presentation.

Dials: variance 10, motion 8, density 5. A blue build universe with a shaded orange SVG torus, orbital satellites, pointer-controlled perspective and floating project portals. Curved SVG lettering preserves a semantic HTML heading. Crossed kinetic ribbons connect the universe to a lime champion capsule and a dark weekly exhibition island. Category arches, oblique corners, soft project vessels and a circular honors display extend the geometry through the product.

Motion: one orbital scene and one ribbon loop; pointer tilt is interaction-driven, sections reveal once as they enter. Visible Pause motion control stops loops, perspective and reveals; reduced-motion produces a static complete scene. Hidden tabs pause loops; keyboard focus pauses the orbital scene. Content and links are available without JavaScript. No camera, WebGL, remote media, or motion framework dependencies.

Files: components/portal.tsx (native SVG sculpture and curved type), components/motion.tsx (control and motion lifecycle), app/otherworld.css (geometry and responsive composition), app/page.tsx (exhibition scenes). Existing functional primitives and product workflows remain shared.

Interaction: Warp space lets visitors bend the sculpture and rearrange the project constellation; Restore orbit returns the original layout. Both states preserve direct project navigation. The honors circle was refined during full-page visual review so all copy stays centered and readable.

Validation: lint, types, formatting, production build, seven domain tests and twelve browser flows pass. Automated checks cover ten public routes at 375/768/1024/1440px, landscape navigation, curation/auth/submission/support workflows, and the new warp/pause/focus/reduced-motion contract.
